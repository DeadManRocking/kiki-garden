UI Painter

Paints every picture the garden shows instead of words, once, in one matching style, then saves them as one zip.
Safe mode: it paints a small batch. One picture that is refused is skipped; it stops at once on a key or credit problem, or after 3 failures in a row. One request per picture, no retries. Pictures already painted are kept and never repainted. Order: the copper watering can first (it sets the style for all the rest), then the others. Tap Paint on any one to roll it again. Rolling the watering can again changes the style, so repaint the rest afterwards. Check your OpenAI usage after the first ten.
